# 게임 제작 과제 기획서

- **게임 제목**: Reverse Pong (가제)
- **장르**: 2D 아케이드 / 액션
- **플레이 인원**: 1인
- **개발 환경**: Visual Studio
- **스테이지 수**: 1개
- **주요 조작 방식**: 마우스
- **예상 플레이 시간**: 약 3~5분

---

# 1. 게임 개요

## 1-1. 게임 소개

본 게임은 고전 아케이드 게임 **Pong**의 공 반사 메커니즘을 변형하여 제작하는 1인용 2D 아케이드 게임이다.

기존 Pong은 화면의 좌우에 위치한 패들을 상하로 움직이며 공을 상대편 방향으로 보내는 것을 핵심 플레이로 한다.

본 게임에서는 이러한 기본적인 공 반사 방식을 유지하면서, 플레이어가 조작하는 하나의 **BAR**가 화면의 좌측과 우측뿐만 아니라 상단과 하단을 포함한 **화면의 네 방향 가장자리 전체를 이동할 수 있도록 확장**한다.

또한 하나의 공만 사용하는 기존 Pong과 달리 화면 내부에는 여러 개의 공이 동시에 움직인다.

플레이어는 화면 가장자리를 이동하면서 공이 화면 밖으로 빠져나가지 않도록 방어하고, BAR에 공을 충돌시켜 진행 방향을 조절하여 화면 중앙에 위치한 **Goal Box** 안으로 모든 공을 넣는 것을 목표로 한다.

---

## 1-2. 게임 기획 의도

기존 Pong은 구조와 조작 방식이 단순하여 누구나 쉽게 이해하고 플레이할 수 있다는 장점이 있다.

본 게임은 이러한 단순성을 유지하면서도 다음과 같은 요소를 추가하여 새로운 플레이 경험을 만드는 것을 목표로 한다.

- 좌우에 제한되어 있던 패들의 이동 범위를 화면 4면 전체로 확장
- 하나가 아닌 여러 개의 공을 동시에 관리
- 단순히 공을 막는 것뿐만 아니라 중앙의 목표 지점으로 공을 유도
- 화면 일부에만 벽을 배치하여 공이 밖으로 빠져나갈 위험 추가
- 마우스를 이용한 빠른 BAR 이동
- 공의 움직임을 관찰하면서 방어와 조준을 동시에 수행

따라서 플레이어는 단순히 공이 오는 위치를 막는 것뿐만 아니라, 여러 공의 위치와 이동 방향을 빠르게 판단해야 한다.

---

## 1-3. 핵심 재미

본 게임에서 제공하고자 하는 핵심 재미는 다음과 같다.

### 빠른 상황 판단

화면 안에는 여러 개의 공이 동시에 존재하기 때문에 플레이어는 각각의 공이 어느 방향으로 이동하고 있는지 지속적으로 확인해야 한다.

특히 벽이 없는 공간으로 향하는 공을 빠르게 발견하여 BAR를 이동시키는 것이 중요하다.

### 공을 막는 수비 플레이

공이 화면 밖으로 빠져나가지 않도록 적절한 위치에 BAR를 이동시켜 공을 받아내야 한다.

화면 전체가 벽으로 막혀 있지 않기 때문에 플레이어가 직접 방어해야 하는 위치가 존재한다.

### 중앙을 향한 조준 플레이

공을 단순히 막는 것만으로는 게임을 클리어할 수 없다.

BAR와 공이 충돌하는 위치를 조절하여 공의 진행 방향을 중앙의 Goal Box 쪽으로 유도해야 한다.

즉, 플레이어는 **공을 막는 것과 공을 Goal Box로 보내는 것을 동시에 수행**해야 한다.

# 2. 핵심 게임 플레이

## 2-1. 기본 게임 흐름

게임이 시작되면 화면 내부에 여러 개의 공이 생성된다.

각 공은 서로 다른 방향으로 이동하며 벽이나 BAR에 충돌하면 반사된다.

플레이어는 마우스를 움직여 화면 가장자리를 따라 BAR를 이동한다.

게임 중 플레이어는 다음 행동을 반복한다.

1. 화면 내부의 공 위치 확인
2. 각 공의 이동 방향 판단
3. 화면 밖으로 빠져나갈 가능성이 있는 공 확인
4. 마우스를 이용하여 BAR 이동
5. BAR로 공을 받아냄
6. 공이 중앙 Goal Box 방향으로 이동하도록 반사
7. Goal Box에 공을 넣음
8. 남아 있는 다른 공을 반복해서 처리
9. 모든 공을 Goal Box에 넣으면 게임 클리어

---

## 2-2. 플레이 구조

게임 플레이는 크게 **수비**와 **조준** 두 가지 요소로 구성된다.

### 수비

화면 가장자리에는 일부 구간에만 고정된 벽이 존재한다.

벽에 공이 부딪히면 자동으로 반사되지만, 벽이 존재하지 않는 공간으로 공이 이동할 경우 화면 밖으로 빠져나갈 수 있다.

플레이어는 이러한 빈 공간으로 이동하여 BAR로 공을 막아야 한다.

### 조준

BAR에 공이 충돌했을 때 단순히 반대 방향으로만 튕기는 것이 아니라, BAR의 어느 위치에 공이 부딪혔는지에 따라 반사 방향이 달라지도록 구현한다.

이를 통해 플레이어가 BAR의 위치를 조절하여 공을 중앙의 Goal Box 방향으로 보낼 수 있도록 한다.

# 3. 게임 화면 구성

게임 화면은 하나의 직사각형 공간으로 구성된다.

화면 중앙에는 Goal Box가 존재하며, 화면 가장자리에는 여러 개의 고정 벽과 공이 빠져나갈 수 있는 빈 공간이 존재한다.

│         └──────┘       │
│                   ○    │
│                        │
└──────      ────────────┘
          ━━━━━
           BAR
