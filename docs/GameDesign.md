# Pong Shift - 게임 기획서

## 1. 게임 개요

- **게임 제목**: Pong Shift
- **장르**: 2D 아케이드 / 액션
- **플레이 인원**: 1인
- **개발 환경**: Visual Studio 2022 / C++ / glc2d
- **조작**: 마우스
- **게임 모드**
  - Multi Ball
  - Maze Ball

Pong Shift는 고전 게임 Pong의 **공과 BAR의 반사**를 기반으로 한 1인용 아케이드 게임이다.

같은 반사 시스템을 사용하지만 두 가지 서로 다른 게임 방식을 제공한다.

| 모드 | 목적 | 핵심 플레이 |
|---|---|---|
| Multi Ball | 여러 공을 최대한 많이 Goal에 넣기 | 빠른 상황 판단과 방어 |
| Maze Ball | 벽을 피해서 공 하나를 Goal까지 이동 | 정밀한 조작과 타이밍 |

---

## 2. 조작 방법

### Multi Ball

마우스로 하나의 BAR를 화면 가장자리를 따라 이동시킨다.

- BAR는 화면 내부로 들어갈 수 없다.
- 상단/하단에서는 가로 형태
- 좌측/우측에서는 세로 형태
- 모서리를 통과하면 방향이 자동으로 변경된다.

### Maze Ball

위쪽과 아래쪽의 BAR 두 개를 하나의 마우스로 동시에 움직인다.

- 두 BAR의 X좌표는 항상 동일하다.
- 마우스를 좌우로 움직이면 두 BAR가 함께 이동한다.
- BAR와 공이 충돌하면 공이 단순 반사된다.

---

## 3. Multi Ball

### 게임 목적

여러 개의 공 중 최대한 많은 공을 화면 중앙의 **Goal**에 넣는다.

### 게임 규칙

- 여러 개의 공이 서로 다른 위치와 방향으로 움직인다.
- 공의 개수는 플레이 테스트 후 결정한다.
- 화면 외곽에는 벽이 있는 구간과 없는 구간이 존재한다.
- 벽에 부딪힌 공은 반사된다.
- 벽이 없는 곳으로 공이 향하면 플레이어가 BAR로 막아야 한다.
- BAR와 공이 충돌하면 단순 반사된다.
- Goal에 들어간 공은 화면에서 제거된다.
- 화면 밖으로 나간 공은 Out 처리되고 다시 생성되지 않는다.

### 점수

**Goal에 들어간 공 1개 = 1점**

예:

> 전체 공 5개 / Goal 3개 / Out 2개  
> **SCORE : 3 / 5**

### 종료 조건

모든 공이 `Goal` 또는 `Out` 상태가 되면 게임을 종료하고 최종 점수를 표시한다.

---

## 4. Maze Ball

### 게임 목적

공 하나를 미로 벽에 부딪히지 않도록 조작하여 최종 Goal까지 이동시킨다.

### 게임 규칙

- 공은 1개만 사용한다.
- 위/아래 BAR 두 개를 동시에 조작한다.
- BAR와 공이 충돌하면 단순 반사된다.
- 화면 내부에는 미로 형태의 장애물이 존재한다.
- **공이 미로 벽에 닿으면 즉시 실패한다.**
- Goal에 도착하면 게임을 클리어한다.
- Goal의 정확한 위치와 미로 구조는 구현 과정에서 조정한다.

### 점수

Maze Ball은 **클리어 시간**을 기록한다.

> GAME CLEAR  
> TIME : 24.37 sec

시간이 짧을수록 좋은 기록이다.

### 종료 조건

- Goal 도착 → **Game Clear**
- 미로 벽 충돌 → **Game Failed**

## 5. 게임 시작 및 재시작

게임을 실행하면 먼저 모드 선택 화면이 표시된다.

```text
┌─────────────────────────┐
│       PONG SHIFT        │
│                         │
│       MULTI BALL        │
│        MAZE BALL        │
└─────────────────────────┘

모드를 선택하면 게임에 필요한 값을 초기화하고 플레이를 시작한다.

게임이 종료된 뒤에는 바로 다시 시작할 수 있으며, 모드 선택 화면으로 돌아가는 기능도 제공한다.

Maze Ball 재시작 시 타이머는 다시 0초로 초기화된다.
